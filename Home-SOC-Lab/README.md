# Home SOC Lab

## Overview

This project focused on building a home Security Operations Center (SOC) environment to gain practical experience in monitoring, detecting, and investigating security events.

## Objectives

* Understand SOC workflows
* Monitor security events
* Analyze logs
* Investigate alerts
* Document findings

## Skills Demonstrated

* Security Monitoring
* Log Analysis
* Alert Investigation
* Threat Detection
